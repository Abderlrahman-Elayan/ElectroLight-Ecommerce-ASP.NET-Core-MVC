# ElectroLight E-Commerce (ASP.NET Core MVC)

## 📌 Overview
ElectroLight is a full-stack e-commerce web application built using ASP.NET Core MVC.  
The project follows a clean layered architecture and provides core e-commerce functionalities such as product and category management, image handling, and dynamic data presentation.

---

## 🚀 Features

- 🛍️ Product Management (Create, Read, Update, Delete)
- 📂 Category Management
- 🖼️ Image Upload & Normalization
- ⚡ Asynchronous Data Loading
- 📊 Featured & Newest Products Display
- 🔄 JSON Endpoints for dynamic operations
- 🔐 Authentication & Authorization (ASP.NET Core Identity)
- 🧑‍💼 Role-based access control (Admin/User)

---

## 🏗️ Architecture

The project follows a **layered architecture**:

- **Presentation Layer (MVC)**  
  Handles UI, Controllers, and Views

- **Application Layer**  
  Business logic and services

- **Domain Layer**  
  Core entities and models

- **Infrastructure Layer**  
  Data access using Entity Framework Core

---

## 🛠️ Technologies Used

- ASP.NET Core MVC  
- Entity Framework Core  
- SQL Server  
- LINQ  
- Dependency Injection  
- Bootstrap (for UI)  

---

## 🔐 Security

- Implemented authentication using ASP.NET Core Identity  
- Role-based authorization to restrict access to admin features  
- Secure handling of user data and protected routes
